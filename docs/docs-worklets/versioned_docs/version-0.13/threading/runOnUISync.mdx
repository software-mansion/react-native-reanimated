# runOnUISync

`runOnUISync` lets you run a [workletized](../fundamentals/glossary.mdx#to-workletize) function synchronously on the [UI Runtime](../fundamentals/runtimeKinds.mdx#ui-runtime).

To compare it with [`scheduleOnUI`](./scheduleOnUI.mdx) and [`runOnUIAsync`](./runOnUIAsync.mdx), see [Running worklets on the UI runtime](../guides/running-on-the-ui-runtime.mdx).

## Reference

```javascript
import { runOnUISync } from 'react-native-worklets';

const myFunction = (num: number): number => {
  'worklet';
  return num + 1;
};

const result: number = runOnUISync(myFunction, 0);

console.log(result); // 1
```

</details>

### Arguments

#### worklet

A function you want to execute on the [UI Runtime](../fundamentals/runtimeKinds.mdx#ui-runtime).

#### args

Arguments to pass to the function.

### Returns

`runOnUISync` returns the return value of the function passed as the first argument. It can only return values that can be converted to a [Serializable](../memory/serializable.mdx).

## Remarks

- The callback passed as the argument is automatically [workletized](../fundamentals/glossary.mdx#to-workletize) and ready to be run on the [UI Runtime](../fundamentals/runtimeKinds.mdx#ui-runtime).
