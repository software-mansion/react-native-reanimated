<Badges version="0.13.0">
  # Oxc plugin
</Badges>

:::note
The Oxc plugin is a port of the [Worklets Babel plugin](./about.md) to Rust, built on top of [Oxc](https://oxc.rs/). It's an opt-in alternative to the Babel plugin, which remains the default for the time being. Only [Bundle Mode](../bundleMode/overview.mdx) is supported.
:::

## Setup

For setup instructions, refer to the [Bundle Mode setup](../bundleMode/setup.mdx?worklets-plugin=oxc#configure-worklets-plugin) with the Oxc plugin selected in the tabs.

## Options

The Oxc plugin accepts the [`importForwarding`](./options.mdx#importforwarding) option and it works the same way as in the Babel plugin.

[`bundleMode`](./options.mdx#bundlemode) and [`strictGlobal`](./options.mdx#strictglobal) are always on and cannot be turned off. The remaining options of the Babel plugin are ignored.

## Notes

Being a port, the Oxc plugin might not cover every edge case that the Babel plugin does. If you find a difference in behavior, please let us know on [GitHub](https://github.com/software-mansion/react-native-reanimated/).
