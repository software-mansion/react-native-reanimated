<Badges version="0.8.0">
  # isWorkletRuntime
</Badges>

Checks if the current runtime is a [Worklet Runtime](../fundamentals/runtimeKinds.mdx#worklet-runtime), either the [UI Runtime](../fundamentals/runtimeKinds.mdx#ui-runtime) or a [Worker Runtime](../fundamentals/runtimeKinds.mdx#worker-runtime).

## Reference

```typescript
import {
  isWorkletRuntime,
  scheduleOnUI,
  scheduleOnRuntime,
  createWorkletRuntime,
} from 'react-native-worklets';

console.log(isWorkletRuntime()); // false

scheduleOnUI(() => {
  // highlight-next-line
  console.log(isWorkletRuntime()); // true
})();

const workerRuntime = createWorkletRuntime();
scheduleOnRuntime(workerRuntime, () => {
  // highlight-next-line
  console.log(isWorkletRuntime()); // true
})();
```

<details>
  <summary>Type definitions</summary>

  ```typescript
  function isWorkletRuntime(): boolean;
  ```
</details>

### Returns

`true` if the current runtime is a [Worklet Runtime](../fundamentals/runtimeKinds.mdx#worklet-runtime), `false` otherwise.

## Remarks

- The function checks the value of `globalThis.__RUNTIME_KIND` to determine the kind of the current runtime. See [getRuntimeKind](./getRuntimeKind.mdx) for more details.
