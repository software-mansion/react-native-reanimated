Checks if the current runtime is a [Worker Runtime](/docs/concepts/runtimeKinds#worker-runtime).

## Reference

<ThreadingSimulation module={ApiIsWorkerRuntimeSnippet} source={ApiIsWorkerRuntimeSource}/>

<details>
  <summary>Type definitions</summary>

  ```typescript
  function isWorkerRuntime(): boolean;
  ```
</details>

### Returns

`true` if the current runtime is the [Worker Runtime](/docs/concepts/runtimeKinds#worker-runtime), `false` otherwise.

## Remarks

- The function checks the value of `globalThis.__RUNTIME_KIND` to determine the kind of the current runtime. See [getRuntimeKind](/docs/utility/getRuntimeKind) for more details.
