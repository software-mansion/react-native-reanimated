Checks if the current runtime is the [UI Runtime](../concepts/runtimeKinds.mdx#ui-runtime).

## Reference

<ThreadingSimulation module={ApiIsUIRuntimeSnippet} source={ApiIsUIRuntimeSource}/>

<details>
  <summary>Type definitions</summary>

  ```typescript
  function isUIRuntime(): boolean;
  ```
</details>

### Returns

`true` if the current runtime is the [UI Runtime](../concepts/runtimeKinds.mdx#ui-runtime), `false` otherwise.

## Remarks

- The function checks the value of `globalThis.__RUNTIME_KIND` to determine the kind of the current runtime. See [getRuntimeKind](./getRuntimeKind.mdx) for more details.
