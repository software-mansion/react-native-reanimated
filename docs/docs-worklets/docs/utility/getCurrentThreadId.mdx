  # getCurrentThreadId
</Badges>

`getCurrentThreadId` returns the id of the thread which currently executes JavaScript on the calling [Runtime](/docs/concepts/runtimeKinds). The returned id is a stringified result of [`std::this_thread::get_id()`](https://en.cppreference.com/cpp/thread/get_id).

### Returns

`getCurrentThreadId` returns a `string` with the id of the current thread. The format of the id is platform-specific.
