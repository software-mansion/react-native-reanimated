# Overview

Bundle Mode is a feature that gives worklet functions access to your whole JavaScript bundle - meaning that any code that's present in the bundle can be executed in any worklet function and on any runtime. This means that third party libraries can be used in worklet functions without the need to patch them. It's also a performance improvement as worklet functions' code can benefit from all the optimizations that pre-compiled bytecode offers.

**Bundle Mode will be the default way of using worklet functions in the future.**

Instructions on how to enable it can be found [here](/docs/bundleMode/setup).

## Legacy Eval Mode

The former way of using worklet functions - where each worklet function is serialized as a string and evaluated individually on the Worklet Runtime - is referred to as **Legacy Eval Mode**. It's still the default mode of running worklet functions, but we strongly recommend opting out of it with the Bundle Mode.
