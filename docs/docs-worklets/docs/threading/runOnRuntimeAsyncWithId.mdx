  # runOnRuntimeAsyncWithId
</Badges>

`runOnRuntimeAsyncWithId` is a variant of [runOnRuntimeAsync](./runOnRuntimeAsync.mdx) where you use the runtime's id instead of the runtime object. It's useful when you don't have access to the runtime object, but you know its id.


## Arguments

### runtimeId

The id of the [Worklet Runtime](../concepts/runtimeKinds.mdx#worklet-runtime) to run the worklet function on. You can get the id from the runtime object by accessing its `runtimeId` property.

### worklet

A reference to a function you want to execute on the [Worklet Runtime](../concepts/runtimeKinds.mdx#worklet-runtime).

### args

Arguments to the function you want to execute on the [Worklet Runtime](../concepts/runtimeKinds.mdx#worklet-runtime).

## Remarks

- `runOnRuntimeAsyncWithId` can target the UI Runtime by passing [UIRuntimeId](./uiRuntimeId.mdx) as the runtime id.

- Errors thrown in the worklet function will cause the Promise to reject with that error.
