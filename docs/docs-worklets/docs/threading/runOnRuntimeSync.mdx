  # runOnRuntimeSync
</Badges>

`runOnRuntimeSync` lets you run a [workletized](../worklets-plugin/about.mdx#autoworkletization) function synchronously on a [Worker Runtime](../concepts/runtimeKinds.mdx#worker-runtime). It's blocking - meaning that it can preempt the runtime from a thread that's currently executing it.

## Arguments

### workletRuntime

The worklet runtime to run the worklet function on.

### worklet

A reference to a function you want to execute on the [Worker Runtime](../concepts/runtimeKinds.mdx#worker-runtime).

### args

Arguments to the function you want to execute on the [Worker Runtime](../concepts/runtimeKinds.mdx#worker-runtime).
