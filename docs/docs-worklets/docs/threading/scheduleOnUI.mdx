# scheduleOnUI

`scheduleOnUI` lets you schedule a function to be executed on the [UI Runtime](../concepts/runtimeKinds.mdx#ui-runtime). The callback executes asynchronously and doesn't return a value.

To compare it with [`runOnUIAsync`](./runOnUIAsync.mdx) and [`runOnUISync`](./runOnUISync.mdx), see [Running worklet functions on the UI runtime](../guides/running-on-the-ui-runtime.mdx).

### Arguments

#### fun

A reference to a function you want to schedule on the [UI Runtime](../concepts/runtimeKinds.mdx#ui-runtime).

#### args

Arguments to pass to the function.

## Remarks

- The callback passed as the argument is automatically [workletized](../worklets-plugin/about.mdx#autoworkletization) and ready to be run on the [UI Runtime](../concepts/runtimeKinds.mdx#ui-runtime).

- On the Web, `scheduleOnUI` schedules work to run on the next animation frame using `requestAnimationFrame`.
