# runOnUISync

`runOnUISync` lets you run a [workletized](../worklets-plugin/about.mdx#autoworkletization) function synchronously on the [UI Runtime](../concepts/runtimeKinds.mdx#ui-runtime).

To compare it with [`scheduleOnUI`](./scheduleOnUI.mdx) and [`runOnUIAsync`](./runOnUIAsync.mdx), see [Running worklet functions on the UI runtime](../guides/running-on-the-ui-runtime.mdx).

### Arguments

#### worklet

A function you want to execute on the [UI Runtime](../concepts/runtimeKinds.mdx#ui-runtime).

#### args

Arguments to pass to the function.

### Returns

`runOnUISync` returns the return value of the function passed as the first argument. It can only return values that can be converted to a [Serializable](../memory/serializable.mdx).

## Remarks

- The callback passed as the argument is automatically [workletized](../worklets-plugin/about.mdx#autoworkletization) and ready to be run on the [UI Runtime](../concepts/runtimeKinds.mdx#ui-runtime).
