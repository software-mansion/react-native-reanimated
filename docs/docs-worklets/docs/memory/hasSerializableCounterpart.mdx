<Badges version="0.14.0">
  # hasSerializableCounterpart
</Badges>

Checks whether Worklets remembers a serialized counterpart of an object. An object has one after [setSerializableCounterpart](/docs/memory/setSerializableCounterpart), or after Worklets [serialized](/docs/memory/serializable) it.

## Reference

```typescript
import {
  hasSerializableCounterpart,
  setSerializableCounterpart,
} from 'react-native-worklets';

const flag = { current: false };
console.log(hasSerializableCounterpart(flag)); // logs `false`

setSerializableCounterpart(flag, { current: true });
console.log(hasSerializableCounterpart(flag)); // logs `true`
```

<details>
  <summary>Type definitions</summary>

## Arguments

### value

The object to check. It's compared by reference.

## Remarks

- On the Web `hasSerializableCounterpart` always returns `false`.
