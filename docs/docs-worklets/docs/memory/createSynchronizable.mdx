<Badges version="0.6.0">
  # createSynchronizable
</Badges>

Creates a new [Synchronizable](./synchronizable.mdx) holding the provided initial value. Returns the created Synchronizable.

By default it creates a [Synchronizable Dynamic](./synchronizable.mdx#synchronizable-dynamic).

You can pass a config option to create [Synchronizable Fixed](./synchronizable.mdx#synchronizable-fixed) instead.

## Arguments

### initialValue

The initial value to be held by the created Synchronizable. As it has to be serialized before passing to C++, it must be one of the supported types listed in the [Serializable](./serializable.mdx) documentation.

With the [`fixedType` option](#config) it isn't serialized and must be a `number` or a `boolean`.

<Badges version="0.13.0">
  ### config
</Badges>

Optional configuration for the Synchronizable. An object with the following properties:

- `fixedType` - when `true`, the created [Synchronizable Fixed](./synchronizable.mdx#synchronizable-fixed) stores its `number` or `boolean` value directly in native memory, without serialization, and exposes the additional [`setDirty`](./synchronizable.mdx#setdirty) method. Defaults to `false`.

## Remarks

- In [Legacy Eval Mode](../bundleMode/overview.mdx#legacy-eval-mode), `createSynchronizable` can be called only on the [RN Runtime](../concepts/runtimeKinds.mdx#rn-runtime). In Bundle Mode, it can be called on any Runtime.
