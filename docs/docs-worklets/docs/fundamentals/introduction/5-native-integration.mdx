We'll build that integration on top of a [Turbo Module](https://reactnative.dev/docs/turbo-native-modules-introduction). You could also do it in an [Expo Module](https://docs.expo.dev/modules/overview/#when-should-i-use-turbo-modules-and) but it's going to be slightly more difficult.
