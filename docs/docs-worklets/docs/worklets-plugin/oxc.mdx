<Badges version="0.13.0">
  # Oxc plugin options
</Badges>

:::note
The Oxc plugin is a port of the [Worklets Babel plugin](./about.mdx) to Rust, built on top of [Oxc](https://oxc.rs/). It's an opt-in alternative to the Babel plugin, which remains the default for the time being. Only [Bundle Mode](../bundleMode/overview.mdx) is supported.
:::

<details>
  <summary>Type definitions</summary>

  ```typescript
  interface PluginOptions {
    extraPlugins?: string[];
    extraPresets?: string[];
    importForwarding?: {
      moduleNames?: string[];
      relativePaths?: string[];
    };
  }
  ```
</details>

## Setup

For setup instructions, refer to the [Bundle Mode setup](../bundleMode/setup.mdx?worklets-plugin=oxc#configure-worklets-plugin) with the Oxc plugin selected in the tabs.

## How to use

Pass an object with the options to the plugin in your `babel.config.js` file. Pass the plugin and its options as a **two-element array**:

```js {8-11}
/** @type {import('react-native-worklets/plugin-oxc').PluginOptions} */
const workletsPluginOptions = {
  importForwarding: {
    moduleNames: ['my-library'],
  },
};

module.exports = {
  ...
  plugins: [
    ...
    [
      'react-native-worklets/plugin-oxc/babel',
      workletsPluginOptions,
    ],
  ],
};
```

## Options

### importForwarding

Defaults to no forwarding (an empty object).

Configures [import forwarding](../bundleMode/importForwarding.mdx). It works the same way as the [`importForwarding`](./options.mdx#importforwarding) option of the Babel plugin.

#### importForwarding.moduleNames

Defaults to an empty array.

List of module names that should be forwarded as imports inside worklet functions. A name also matches its subpaths: with `my-library` in the list, imports from `my-library/some-file` are forwarded too, but imports from `my-library-extra` aren't. See [`importForwarding.moduleNames`](./options.mdx#importforwardingmodulenames) of the Babel plugin.

The Oxc plugin always forwards `react-native-worklets` and `react-native/Libraries/Core/setUpXHR`. The names in this list are added to them.

#### importForwarding.relativePaths

Defaults to an empty array.

List of paths that determine whether a module forwards its **relative** imports inside worklet functions. If the path of a module matches any of the paths, all relative imports inside the worklet functions of that module are forwarded. See [`importForwarding.relativePaths`](./options.mdx#importforwardingrelativepaths) of the Babel plugin.

The Oxc plugin always does this for modules of `react-native-worklets`. The paths in this list are added to it.

### extraPlugins

Accepted but ignored. The Oxc plugin cannot run other Babel plugins on worklet functions, so it prints a warning when this list is not empty. Add these plugins next to the Oxc plugin in your `babel.config.js` instead. See [`extraPlugins`](./options.mdx#extraplugins) of the Babel plugin.

### extraPresets

Accepted but ignored, in the same way as [`extraPlugins`](#extraplugins). See [`extraPresets`](./options.mdx#extrapresets) of the Babel plugin.

### Options that are always on

[`bundleMode`](./options.mdx#bundlemode) and [`strictGlobal`](./options.mdx#strictglobal) are always on and cannot be turned off.

### Other Babel plugin options

The Oxc plugin ignores all other [Babel plugin options](./options.mdx#options).

## Notes

Being a port, the Oxc plugin might not cover every edge case that the Babel plugin does. If you find a difference in behavior, please let us know on [GitHub](https://github.com/software-mansion/react-native-reanimated/).
