# Introduction

## What is React Native Worklets?

React Native Worklets is a library that allows you to run JavaScript code in parallel on multiple threads and runtimes.

Try the example below to compare a busy JavaScript thread with work distributed across multiple threads. Enable Worklets and press the app button to see the difference.
