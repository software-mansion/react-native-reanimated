  # SharedTransition
</Badges>

`SharedTransition` is a builder that sets how a shared view moves. Pass it to the [`sharedTransitionStyle`](./shared-transition-props.mdx#sharedtransitionstyle) prop. Without modifiers, the view moves with a 500 ms [`withTiming`](../animations/withTiming.mdx) animation.

## Reference

```tsx
import Animated, { SharedTransition, Easing } from 'react-native-reanimated';

// highlight-next-line
const transition = SharedTransition.duration(400).easing(Easing.out(Easing.cubic));

function Photo() {
  return (
    <Animated.View
      sharedTransitionTag="photo"
      // highlight-next-line
      sharedTransitionStyle={transition}
    />
  );
}
```

## Modifiers

### Easing <Optional/>

Easing modifiers use the [`withTiming`](../animations/withTiming.mdx) function.

```javascript
SharedTransition.duration(400).easing(Easing.out(Easing.cubic));
```

- `.easing(easingFunction: EasingFunction)` sets the animation curve. Defaults to `Easing.inOut(Easing.quad)`.

:::note
The `.easing(...)` modifier has no effect when you use `.springify()`.
:::

### Spring-based <Optional/>

Spring-based modifiers use the [`withSpring`](../animations/withSpring.mdx) function. As in the `withSpring` config, a spring is duration-based (`duration` and `dampingRatio`) or physics-based (`mass`, `damping` and `stiffness`).

```javascript
// duration-based
SharedTransition.springify(600).dampingRatio(0.7);

// physics-based
SharedTransition.springify().damping(15).stiffness(150);
```

- `.springify(duration?: number)` uses a spring for the transition. The optional argument sets the perceptual duration of the spring in milliseconds. The spring stops after about 1.5 times this value. Defaults to `500`.
- `.dampingRatio(value: number)` sets how damped the spring is. Value `1` means that the spring is critically damped, and value `>1` means that the spring is overdamped. Defaults to `1`.
- `.damping(value: number)` sets how quickly the spring stops. Higher damping means that the spring stops faster. Defaults to `120`.
- `.mass(value: number)` is the weight of the spring. A lower value makes the animation faster. Defaults to `4`.
- `.stiffness(value: number)` sets the stiffness of the spring. Defaults to `900`.
- `.overshootClamping(value: boolean)` sets whether the spring can go past its target. Defaults to `false`.
- `.energyThreshold(value: number)` sets the relative energy below which the spring stops. Defaults to `6e-9`.

:::info
If you set `damping`, `mass` or `stiffness` without a duration and without `dampingRatio`, the spring is physics-based. In all other cases, the spring uses a duration, which is 500 ms by default.
:::

### Common <Optional/>

```javascript
SharedTransition.duration(400)
  .delay(100)
  .reduceMotion(ReduceMotion.System)
  .withCallback((finished) => {
    'worklet';
    console.log(`finished without interruptions: ${finished}`);
  });
```

- `.duration(duration: number)` sets the length of the animation in milliseconds. Defaults to `500`.
- `.delay(duration: number)` sets the time before the animation starts, in milliseconds. Defaults to `0`.
- `.reduceMotion(reduceMotion: ReduceMotion)` disables SET for the view when reduced motion applies. If either view opts out, SET does not run. The navigator still controls the screen transition.
- `.withCallback(callback: (finished: boolean) => void)` sets a function that runs on the UI runtime once, when the transition ends. The callback must be a worklet. This builder chain does not workletize it automatically. `finished` is `true` when the view lands at its target, and `false` when the transition stops before that or does not move the view.

The callback runs in the frame after the view lands. A shared view that moves inside its moving parent lands together with the parent, so their callbacks run in the same frame. A layout change of the target does not end the transition. A reverse, a new view that takes the shared tag of the target, or a new transition of the same tag ends the old transition, so its callback gets `false`. Then the new transition reports its own result.

For iOS back gestures, the callback of a view that moves reports `true` when navigation commits. It reports `false` if the gesture cancels or SET stops. If the view does not move, the callback gets `false` when the gesture starts.

### Shared transition modifiers <Optional/>

- [`.fadeContent(config?)`](./children-of-shared-views.mdx#fadecontent) fades the children of the view during the transition.
- [`.custom(animation)`](./custom-animations.mdx) uses your own animation worklet.
- [`.progressAnimation(animation)` and `.defaultTransitionType(type)`](./progress-transitions.mdx) set the transition that follows the progress of the screen change.

## Remarks

- `.springify()` sets the duration again. Call `.springify(duration)` with the duration that you want, not `.duration(...)` before `.springify()`.
- The transition uses the builder of the view that it starts from. See [`sharedTransitionStyle`](./shared-transition-props.mdx#sharedtransitionstyle).
