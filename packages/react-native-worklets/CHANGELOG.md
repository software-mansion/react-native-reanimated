# Changelog

## 0.14.0 — 2026-11-19

### 🎉 New features

- Warn when an `importForwarding.relativePaths` entry has only common folder names such as `src`, and add the `silenceDangerousPathsWarning` plugin option to turn the warning off. ([#11415](https://github.com/software-mansion/react-native-reanimated/pull/11415) by [@tjzel](https://github.com/tjzel))
- Add `WebSocket` on Worklet Runtimes. ([#11157](https://github.com/software-mansion/react-native-reanimated/pull/11157) by [@tjzel](https://github.com/tjzel))
- Add `abortWorkletRuntime` and the `abortable` runtime option to stop a Worker Runtime, dropping its pending work and rejecting the matching promises. ([#11063](https://github.com/software-mansion/react-native-reanimated/pull/11063) by [@tshmieldev](https://github.com/tshmieldev))
- Add cross-runtime stack traces in development builds, when `ENABLE_CROSS_RUNTIME_STACK_TRACES` is enabled, to errors thrown by functions run with `scheduleOnRN` and `runOnRNSync`. ([#10798](https://github.com/software-mansion/react-native-reanimated/pull/10798) by [@tshmieldev](https://github.com/tshmieldev))
- Add typed `createSerializable` variants, for example `createSerializableArray` and `createSerializableMap`, that accept only one type of value. ([#10770](https://github.com/software-mansion/react-native-reanimated/pull/10770) by [@tshmieldev](https://github.com/tshmieldev))
- Add `runOnRNSync` to run a function synchronously on the RN Runtime, including from UI and Worker Runtimes when Bundle Mode is enabled. ([#10767](https://github.com/software-mansion/react-native-reanimated/pull/10767) by [@tshmieldev](https://github.com/tshmieldev))
- Add `setSerializableMapping`, `getSerializableMapping`, `hasSerializableMapping` and `removeSerializableMapping` to control the value that other runtimes receive in place of an object, and deprecate `serializableMappingCache`. ([#10758](https://github.com/software-mansion/react-native-reanimated/pull/10758) by [@tshmieldev](https://github.com/tshmieldev))
- Support `import()` of lazy Metro chunks on Worklet Runtimes in Bundle Mode. ([#10711](https://github.com/software-mansion/react-native-reanimated/pull/10711) by [@tjzel](https://github.com/tjzel))
- Add the Bundle Mode patches for `metro` and `metro-runtime` 0.87.0. ([#10455](https://github.com/software-mansion/react-native-reanimated/pull/10455) by [@jslok](https://github.com/jslok))
- Read the iOS dev bundle in Bundle Mode from the file that React Native 0.88 and newer persists, instead of downloading it again. ([#10181](https://github.com/software-mansion/react-native-reanimated/pull/10181) by [@tjzel](https://github.com/tjzel))

### 🐛 Bug fixes

- Run the remaining frame finalizers in the next frame when one of them throws. ([#11431](https://github.com/software-mansion/react-native-reanimated/pull/11431) by [@tjzel](https://github.com/tjzel))
- Report an error thrown by a microtask at the checkpoint of a scheduled worklet the same way as an error thrown by the worklet, instead of crashing the app in debug builds. ([#11421](https://github.com/software-mansion/react-native-reanimated/pull/11421) by [@tjzel](https://github.com/tjzel))
- Run the microtasks queued by a synchronous call into a Worklet Runtime (`runOnUISync`, `runOnRuntimeSync`, and the calls Reanimated makes for events) when the outermost call into that runtime returns, instead of leaving them for a later task. ([#11410](https://github.com/software-mansion/react-native-reanimated/pull/11410) by [@tjzel](https://github.com/tjzel))
- Make `importForwarding.moduleNames` match only exact module names, so `my-library` no longer forwards imports from `my-library/utils` unless that subpath is also in the list. ([#11402](https://github.com/software-mansion/react-native-reanimated/pull/11402) by [@tjzel](https://github.com/tjzel))
- Fix the UI runtime frame loop running on every vsync on Android when React starts without an Activity and no headless JS task is active. ([#11400](https://github.com/software-mansion/react-native-reanimated/pull/11400) by [@tjzel](https://github.com/tjzel))
- Fix the iOS, tvOS and macOS builds failing on Xcode 27 because of the deployment target of the privacy manifest bundle. ([#11374](https://github.com/software-mansion/react-native-reanimated/pull/11374) by [@tjzel](https://github.com/tjzel))
- Request UI Runtime animation frames only when callbacks or finalizers are pending instead of on every frame. ([#11372](https://github.com/software-mansion/react-native-reanimated/pull/11372) by [@tjzel](https://github.com/tjzel))
- Autoworkletize the inline `withCallback`, `custom` and `progressAnimation` functions of `SharedTransition` builder chains, and layout animation callbacks after `reduceMotion`, `dampingRatio` or `withTargetValues`, in the Babel and Oxc plugins. ([#11283](https://github.com/software-mansion/react-native-reanimated/pull/11283) by [@pawicao](https://github.com/pawicao))
- Stop the Android dev bundle download in Bundle Mode from blocking forever when the development server stops sending data. ([#11167](https://github.com/software-mansion/react-native-reanimated/pull/11167) by [@tjzel](https://github.com/tjzel))
- Fix `performance.now()` on Worklet Runtimes on iOS to use the same clock as the React Native Runtime. ([#11156](https://github.com/software-mansion/react-native-reanimated/pull/11156) by [@tjzel](https://github.com/tjzel))
- Fix a Shareable treating a new Worker Runtime as its host when the new runtime reuses the memory address of the destroyed host runtime. ([#11140](https://github.com/software-mansion/react-native-reanimated/pull/11140) by [@tjzel](https://github.com/tjzel))
- Autoworkletize worklet callbacks of `runOnRuntimeAsyncWithId`, `createWorkletRuntime`, `createShareable`, `registerCustomSerializable`, the `withTiming` `easing` option and `useHandler` in the Babel and Oxc plugins. ([#11083](https://github.com/software-mansion/react-native-reanimated/pull/11083) by [@tjzel](https://github.com/tjzel))
- Fix crashes and use-after-free errors when a Worklet Runtime is created at the memory address of a destroyed one: Worklets now identify runtimes by their React Native instance and runtime id instead of their address, so values cached for a destroyed runtime, Remote Functions hosted on it and Networking callbacks are never read or released through another runtime. ([#11073](https://github.com/software-mansion/react-native-reanimated/pull/11073) by [@tjzel](https://github.com/tjzel))
- Rebase relative `require()` calls inside worklet bodies in Bundle Mode also in files that are not in `importForwarding.relativePaths`. ([#10935](https://github.com/software-mansion/react-native-reanimated/pull/10935) by [@tjzel](https://github.com/tjzel))
- Fix a worklet that assigns to a captured variable failing with `invalid assignment left-hand side` on Hermes when Bundle Mode is disabled. ([#10889](https://github.com/software-mansion/react-native-reanimated/pull/10889) by [@tshmieldev](https://github.com/tshmieldev))

## 0.13.0 — 2026-09-18

### 🛠 Breaking changes

- Omit empty worklet closures and export closure-free worklets directly in Bundle Mode without factory wrappers. ([#10517](https://github.com/software-mansion/react-native-reanimated/pull/10517) by [@tshmieldev](https://github.com/tshmieldev))
- Store worklet closures as arrays instead of objects. ([#10506](https://github.com/software-mansion/react-native-reanimated/pull/10506) by [@tshmieldev](https://github.com/tshmieldev))
- Removed the networking preview together with its `FETCH_PREVIEW_ENABLED` feature flag. ([#10250](https://github.com/software-mansion/react-native-reanimated/pull/10250) by [@tjzel](https://github.com/tjzel))
- Remove the Serializable handle - `SerializableInitializer`, `createSerializableInitializer` and the `__init` clone path are gone. `Serializable::ValueType::HandleType` stays in the Compat Stable API enum for ABI compatibility and `extractSerializable` throws for it. ([#10414](https://github.com/software-mansion/react-native-reanimated/pull/10414) by [@tjzel](https://github.com/tjzel))
- `makeShareable` now serializes its value eagerly into a retaining Serializable instead of rebuilding it lazily on each runtime through a handle. ([#10412](https://github.com/software-mansion/react-native-reanimated/pull/10412) by [@tjzel](https://github.com/tjzel))
- Remove worklet context objects from the Babel plugin. ([#10411](https://github.com/software-mansion/react-native-reanimated/pull/10411) by [@tjzel](https://github.com/tjzel))
- Change the C++ `Synchronizable` interface to operate on `std::variant` values. Getters return a `Serializable`, a `double` or a `bool`, and `setBlocking` takes either a `Serializable` or a plain value. ([#10294](https://github.com/software-mansion/react-native-reanimated/pull/10294) by [@tjzel](https://github.com/tjzel))
- Add virtual `setDirty` to the C++ `Synchronizable` interface. `SynchronizableDynamic` throws from it. ([#10295](https://github.com/software-mansion/react-native-reanimated/pull/10295) by [@tjzel](https://github.com/tjzel))
