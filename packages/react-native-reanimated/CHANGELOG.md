# Changelog

## 4.8.0 — 2026-11-19

### 🎉 New features

- Support Android shared element transitions between two views in the same React Native Modal. ([#11260](https://github.com/software-mansion/react-native-reanimated/pull/11260) by [@pawicao](https://github.com/pawicao))
- Shared Element Transitions are now enabled by default. Set the `ENABLE_SHARED_ELEMENT_TRANSITIONS` static feature flag to `false` to turn them off. ([#11146](https://github.com/software-mansion/react-native-reanimated/pull/11146) by [@pawicao](https://github.com/pawicao))
- Add `fadeOut.end` and `fadeIn.duration` options to `SharedTransition.fadeContent()`. ([#11044](https://github.com/software-mansion/react-native-reanimated/pull/11044) by [@pawicao](https://github.com/pawicao))
- Play the `entering` animation of a fading direct child of the target view when a `SharedTransition.fadeContent()` transition lands. ([#11035](https://github.com/software-mansion/react-native-reanimated/pull/11035) by [@pawicao](https://github.com/pawicao))
- Add `SharedTransition.fadeContent()`, which fades the children of a shared view out while it moves and fades the children of the target view in when it lands. ([#11033](https://github.com/software-mansion/react-native-reanimated/pull/11033) by [@pawicao](https://github.com/pawicao))
- Add support for animating `borderCurve`, `writingDirection`, `verticalAlign` and `objectFit` styles. ([#10904](https://github.com/software-mansion/react-native-reanimated/pull/10904) by [@tshmieldev](https://github.com/tshmieldev))
- Restore custom shared element transitions with `SharedTransition.custom()`, `.progressAnimation()` and `.defaultTransitionType()`, including the Reanimated 3 values and the `transformMatrix` output, interpolate every changed property in iOS progress transitions, and fix the interpolation of a transform matrix rotated by exactly 90 or -90 degrees around the Y axis. ([#10885](https://github.com/software-mansion/react-native-reanimated/pull/10885) by [@bartlomiejbloniarz](https://github.com/bartlomiejbloniarz))
- Show shared element transitions above iOS modals and hide the shared element in the snapshot of a closing iOS modal that holds a nested stack. ([#10884](https://github.com/software-mansion/react-native-reanimated/pull/10884) by [@bartlomiejbloniarz](https://github.com/bartlomiejbloniarz))
- Add support for shared values as children of `Animated.Text`, including mixed with static text like `<Animated.Text>{sv}%</Animated.Text>`. ([#10713](https://github.com/software-mansion/react-native-reanimated/pull/10713) by [@tshmieldev](https://github.com/tshmieldev))
- Add `backgroundImage` support to CSS animations and CSS transitions, with interpolation of gradient colors, color stop positions, angle direction, and radial size and position on native and a CSS gradient string on web. ([#10193](https://github.com/software-mansion/react-native-reanimated/pull/10193) by [@Titozzz](https://github.com/Titozzz))

## 4.7.0 — 2026-09-18

### 🛠 Breaking changes

- `AnimatedRefOnUI` is now a `ShareableHost<ShadowNodeWrapper | null>` read with `.value` instead of a callable, and `AnimatedRefOnJS` was renamed to `AnimatedRefOnRN`. `measure` on an unmounted ref now returns `null` and warns instead of calling into `_measure`. ([#10413](https://github.com/software-mansion/react-native-reanimated/pull/10413) by [@tjzel](https://github.com/tjzel))
- Remove the `USE_SYNCHRONIZABLE_FOR_MUTABLES` feature flag. Mutables always use Synchronizable state now. ([#10298](https://github.com/software-mansion/react-native-reanimated/pull/10298) by [@tjzel](https://github.com/tjzel))
- Make the light-tree layout animations proxy the default. Enable the new `USE_LEGACY_LAYOUT_ANIMATIONS_PROXY` feature flag to roll back to the previous implementation. The legacy proxy does not support Shared Element Transitions, so `ENABLE_SHARED_ELEMENT_TRANSITIONS` must be off when you enable it. ([#10423](https://github.com/software-mansion/react-native-reanimated/pull/10423) by [@pawicao](https://github.com/pawicao))

### 🎉 New features

- Run `shadowColor` CSS transitions on the Android platform animation path on Android 9 and newer. ([#10547](https://github.com/software-mansion/react-native-reanimated/pull/10547) by [@MatiPl01](https://github.com/MatiPl01))
- Run CSS transitions for `backgroundColor`, `borderColor`, and numeric `borderRadius` on the Android platform animation path. ([#10310](https://github.com/software-mansion/react-native-reanimated/pull/10310) by [@MatiPl01](https://github.com/MatiPl01))
- Add `backgroundImage` support to animated styles. Linear and radial gradients are accepted as objects or CSS strings and processed on the UI thread. ([#10486](https://github.com/software-mansion/react-native-reanimated/pull/10486) by [@tshmieldev](https://github.com/tshmieldev))
- Add iOS Swift Package Manager support via `Package.swift` and SPM integration metadata in `react-native.config.js`, with a dependency on `RNWorklets`. ([#10472](https://github.com/software-mansion/react-native-reanimated/pull/10472) by [@kacperzolkiewski](https://github.com/kacperzolkiewski))
